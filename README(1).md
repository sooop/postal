# 우편번호 검색 Chrome 확장 프로그램

우정사업본부 우편번호 검색 서비스를 편리하게 이용할 수 있는 Chrome 확장 프로그램입니다.

## 설치 방법

1. 이 폴더의 모든 파일을 컴퓨터에 다운로드합니다.

2. Chrome 브라우저를 열고 주소창에 다음을 입력합니다:
   ```
   chrome://extensions/
   ```

3. 오른쪽 상단의 "개발자 모드"를 켭니다.

4. "압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭합니다.

5. 다운로드한 폴더(zipcode-extension)를 선택합니다.

6. 확장 프로그램이 설치되고 Chrome 툴바에 아이콘이 나타납니다.

## 사용 방법

1. Chrome 툴바의 우편번호 검색 아이콘을 클릭합니다.

2. 검색창에 주소를 입력합니다.
   - 예: "강남구 테헤란로"
   - 예: "판교동 123"
   - 예: "도움5로 19"

3. 검색 버튼을 클릭하거나 Enter를 누릅니다.

4. 검색 결과를 클릭하면 우편번호와 주소가 클립보드에 복사됩니다.

## 주의사항

**중요**: 이 확장 프로그램은 우정사업본부 웹사이트를 스크래핑하는 방식으로 동작합니다.

- 웹사이트 구조가 변경되면 작동하지 않을 수 있습니다.
- 실제 사용 시 페이지 구조에 맞게 `popup.js`의 파싱 로직을 수정해야 할 수 있습니다.
- CORS 정책으로 인해 일부 기능이 제한될 수 있습니다.

## 커스터마이징

실제 우정사업본부 웹사이트의 HTML 구조를 확인한 후 `popup.js` 파일의 
`parseSearchResults()` 함수를 수정하여 정확한 파싱이 가능하도록 조정하세요.

### 파싱 로직 수정이 필요한 경우:

1. Chrome 개발자 도구(F12)로 우편번호 검색 페이지의 HTML 구조 확인
2. 결과 테이블/목록의 클래스명과 구조 파악
3. `popup.js`의 선택자(querySelector) 수정

## 대안: 공식 API 사용

더 안정적인 서비스를 위해서는 공공데이터포털의 공식 API 사용을 권장합니다:
- https://www.data.go.kr
- "우편번호" 검색 → API 신청 (무료, 자동승인)

## 파일 구성

- `manifest.json` - 확장 프로그램 설정
- `popup.html` - 팝업 UI
- `popup.css` - 스타일
- `popup.js` - 검색 로직
- `icon*.png` - 확장 프로그램 아이콘

## 문제 해결

### 검색이 작동하지 않는 경우:
1. Chrome 개발자 도구(F12) 콘솔에서 오류 확인
2. 우정사업본부 웹사이트 구조 변경 여부 확인
3. `popup.js`의 URL과 파싱 로직 수정

### CORS 오류가 발생하는 경우:
- `manifest.json`의 `host_permissions` 확인
- 공식 API 사용 검토

## 라이선스
